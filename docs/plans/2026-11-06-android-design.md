# 安卓任务展示端设计

## 已确认范围

用户选择同一局域网、安卓 WebView 方案。只展示任务列表、状态筛选、详情、进展摘要、执行结果与阻塞原因；支持前台自动刷新、手动刷新、断网提示。无任务操作、账号、推送、扫码、多设备或公网隧道。

## 最小架构

- `src/mobile/` 提供独立 HTTPS 只读网关与轻量 HTML/CSS/JavaScript 页面；通过现有本机管理 API 读取任务，不直接打开数据库、不改变运行时或管理端安全策略。
- 网关只接受任务列表、详情和固定静态资源 GET；请求路径、查询参数和输出字段使用白名单。不得泛代理 DSH、设置、会话、环境变量或写操作。
- 电脑命令生成局域网自签证书及随机只读访问密钥，连接信息包含 HTTPS 地址、证书指纹和密钥。私有目录保存，首次在手机粘贴，之后记住。启动单独命令才监听；默认不启动，不修改现有服务。
- `apps/android/` 使用 Android 平台 Java + WebView，无跨端框架。精确匹配目标地址与证书，不绕过 TLS 错误。连接凭据保存在应用私有、禁止备份的存储中；仅需网络权限。应用内不允许导航到其他来源。
- 前台每 5 秒刷新，后台停止；保留最近一次成功数据并注明断线，切换任务或筛选时丢弃旧请求结果。任务内容作为文本展示，不执行 HTML。

## 参考与取舍

参考 [dsh-mobile Android](https://github.com/saya-ch/dsh-mobile/tree/main/apps/mobile) 的 WebView 架构，不复制其完整控制权限及配对、隧道、扩展系统。原生页面需要重复实现展示逻辑；独立网页与 APK 壳更简单。

## 验收

1. 安装 APK，粘贴连接信息后查看列表/筛选/分页及详情；重新打开保留连接。
2. 前台自动/手动刷新，后台停止；服务离线明确提示且不把旧任务显示成新任务。
3. 未授权、错误密钥、跨来源、写请求、非白名单路径均拒绝；不输出管理设置、环境变量、执行目录或会话入口。
4. 证书或地址不匹配时连接失败；访问密钥不进入 URL、日志或第三方请求。
5. 通过现有 `pnpm check`，构建 APK；运行真实 HTTPS 与实际页面冒烟，具备模拟器时验证 Android 安装和连接。没有设备时明确验证限制。
