# 安卓任务展示端设计

## 已确认范围

用户选择同一局域网、安卓 WebView 方案。只展示任务列表、状态筛选、详情、进展摘要、执行结果与阻塞原因；支持前台自动刷新、手动刷新、断网提示。无任务操作、账号、推送、扫码、多设备或公网隧道。

## 最小架构

- `src/mobile/` 提供独立内网 HTTP 只读网关与轻量页面；通过现有本机管理 API 读取任务，不直接打开数据库、不改变运行时或管理端安全策略。
- 任务入口只接受列表、详情和固定静态资源 GET；唯一 POST 是密码登录，不允许任务写操作。请求路径、查询参数和输出字段使用白名单。
- 用户明确选择 HTTP＋单个访问密码，无账号、TLS、证书、配对密钥。电脑端仅保存 scrypt 加盐摘要，登录成功发放 HttpOnly/SameSite 会话 Cookie；网关重启后需重新登录。密码和任务内容在内网明文传输，仅用于可信网络。
- `apps/android/` 使用 Android 平台 Java + WebView，无跨端框架。只保存服务器地址；输入密码在网页完成，不写原生存储。只允许选定私有 IPv4 来源，禁用备份，仅需网络权限。
- 前台每 5 秒刷新，后台停止；保留最近一次成功数据并注明断线，切换任务或筛选时丢弃旧请求结果。任务内容作为文本展示，不执行 HTML。

## 参考与取舍

参考 [dsh-mobile Android](https://github.com/saya-ch/dsh-mobile/tree/main/apps/mobile) 的 WebView 架构，不复制其完整控制权限及配对、隧道、扩展系统。原生页面需要重复实现展示逻辑；独立网页与 APK 壳更简单。

## 验收

1. 安装 APK，填写服务器地址、输入访问密码后查看列表/筛选/分页及详情；重新打开保留地址与有效会话。
2. 前台自动/手动刷新，后台停止；服务离线明确提示且不把旧任务显示成新任务。
3. 未登录、错误密码、跨来源、任务写请求、非白名单路径均拒绝；不输出管理设置、环境变量、执行目录或会话入口。
4. 不接受公网或第三方页面；密码不进入 URL、日志或本地明文配置。中文页面和截图正常显示。
5. 通过现有 `pnpm check`，构建 APK；运行真实 HTTP 与实际页面冒烟，具备模拟器时验证 Android 安装和连接。没有设备时明确验证限制。
